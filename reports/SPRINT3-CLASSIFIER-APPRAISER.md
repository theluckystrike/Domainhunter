## SECTION 4: SCORING METHODOLOGY

Each domain scored on the Sprint 3 framework:

```
Component           Weight    Method
------------------------------------------------------------
backlink_quality     35%     Estimated from domain age, name recognition,
                             niche authority signals, clientRenewProhibited
                             indicating previous active use
referring_domains    20%     Estimated from DA/age correlation and
                             niche competitiveness
archive_history      15%     Domain age as proxy (older = more archive
                             snapshots = better content recovery potential)
tool_opportunity     15%     Keyword-tool fit, search volume match,
                             tool build complexity, monetization clarity
domain_rating        10%     Estimated DA/DR from registrar signals,
                             domain age, and niche positioning
price                 5%     Inverse cost scoring (cheaper = higher score)
```

### Status Decoder
| WHOIS Status | Meaning | Action |
|-------------|---------|--------|
| `No match` | Domain is UNREGISTERED | Register immediately at any registrar |
| `redemptionPeriod` | Owner let it expire, 30-day recovery window ending | Backorder via DropCatch/NameJet |
| `clientRenewProhibited` (GoDaddy) | In GoDaddy's expiration pipeline, NOT being renewed | Will appear at GoDaddy Auctions, then Closeout |
| `clientTransferProhibited` only | Normal active registration | Monitor for future expiration |
| `ok` | Normal, minimal security | May indicate low owner engagement |
