## Goal

Buy GoDaddy Auctions membership ($4.99/year) so we can bid on expired domain auctions and buy closeout domains. This is now our PRIMARY acquisition strategy for cytheris.com, ghostautonomy.com, and bside.com — cheaper than DropCatch.

## Steps (in order)

### Step 1: GoDaddy Account

1. Go to https://www.godaddy.com
2. Log in (or create account if needed)
3. Complete any profile requirements (name, address, payment method)

### Step 2: Buy Auctions Membership ($4.99/year)

1. Go to https://auctions.godaddy.com
2. Look for "Join" or "Membership" or "Subscribe" button
3. Choose the **basic membership** ($4.99/year) — NOT the expensive plans
4. Pay with credit card
5. Confirm purchase

### Step 3: Add Domains to Watchlist

Once membership is active:

1. Search for **cytheris.com** at auctions.godaddy.com
2. Add to watchlist / set up alert
3. Search for **ghostautonomy.com** — add to watchlist
4. Search for **bside.com** — add to watchlist

> Note: These domains may not appear in auctions yet. They'll appear:
> - cytheris.com: ~Jun 30 (auction) or ~Jul 10 (closeout)
> - ghostautonomy.com: ~Jul 3 (auction) or ~Jul 13 (closeout)
> - bside.com: ~Jul 19 (auction) or ~Jul 29 (closeout)

### Step 4: Enable Alerts

1. Go to Account Settings → Notifications/Alerts
2. Enable email + push alerts for watched domains
3. Enable "auction ending soon" notifications
4. Enable "closeout available" notifications

### Step 5: Get API Key (Optional, for future automation)

1. Go to https://developer.godaddy.com/keys
2. Create a new API key (Production environment)
3. Copy the **API Key** and **API Secret**
4. Report back with these values

## Why This Matters

GoDaddy controls 29 registrars' expired domain flow. Our target domains (cytheris.com on GoDaddy, ghostautonomy.com on Wild West/GoDaddy) will:

1. **Day 26 after expiry**: Enter GoDaddy Auction (10-day, min bid $12)
2. **Day 36**: If no bids → Closeout (Buy Now price: $9→$8→$7→$6→$5 over 5 days)
3. **Day 41**: If unsold → released to registry for deletion
4. **Day 77**: DROPS (DropCatch gets a chance here, but only as LAST RESORT)

**Cheapest path: Buy at Closeout = $5-$9 + $23 renewal = $28-$32 total**
vs DropCatch = $59+ (and only if GoDaddy pipeline fails)
