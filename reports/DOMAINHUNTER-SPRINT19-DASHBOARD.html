ETV Reality Check

The Phantom ETV Problem

DataForSEO's ETV uses cached/historical keyword positions, not live SERP data. When a domain goes offline, Google removes it from SERPs within days-weeks, but DataForSEO's Labs database still shows the old positions.

1. Domain ranks for keyword X at position Y (recorded by DataForSEO)
2. Domain goes offline → Google removes from SERPs
3. DataForSEO Labs still shows old position (cached, days-weeks behind)
4. ETV calculation: CTR × Volume × CPC = PHANTOM ETV
5. Live SERP check: domain NOT found → Real ETV = $0

  1. Gate 1: Classification (free) — Is domain generic or brand-specific?

  4. Gate 4: Brand split (free) — Brand traffic >50% = skip
