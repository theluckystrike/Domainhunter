What image format should I use?

JPEG — Best for photographs. Smaller file sizes with lossy compression. No transparency support.
PNG — Best for graphics, screenshots, logos. Lossless with transparency support. Larger files.
WebP — Modern format with excellent compression. Supports transparency. ~30% smaller than JPEG at same quality. Supported by all modern browsers.
BMP — Uncompressed bitmap. Very large files. Use only when lossless raw data is needed.

Is batch conversion supported?

Yes. You can select multiple files at once or add files in batches. All files are converted to the same target format with the same quality settings. Each file can be downloaded individually, or you can download all at once.

Are my images uploaded anywhere?

No. All conversion happens entirely in your browser using the HTML5 Canvas API. Your images never leave your device. This tool works offline once the page is loaded.
