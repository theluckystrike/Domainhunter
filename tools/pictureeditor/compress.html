How does image compression work?

This tool uses your browser's built-in Canvas API to re-encode images at a lower quality setting. For JPEG and WebP, reducing quality removes fine details that are barely visible but take up significant file space. PNG compression is lossless — the file is re-encoded for optimal size.

Is my image uploaded anywhere?

No. All compression happens entirely in your browser using JavaScript. Your images never leave your device. This tool works offline once loaded.

What quality setting should I use?

For photos shared online: 70-80% gives excellent results with major size savings. For print-quality images: use 90-95%. For thumbnails or previews: 50-60% is fine. WebP format generally gives the best quality-to-size ratio.
