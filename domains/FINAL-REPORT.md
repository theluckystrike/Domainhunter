## PREMIUM DETECTION ALGORITHM

### How We Solved It
DNS/WHOIS cannot detect premium pricing. We reverse-engineered Porkbun's checkout API:

```
1. GET https://porkbun.com/checkout/search/{word}?tlds={tldlist}
   → Extract: checkId, searchHash, csrf_pb cookie

2. Wait 4 seconds (server-side availability check)

3. POST https://porkbun.com/api/domains/getChecks
   Headers: X-Requested-With: XMLHttpRequest
   Body: checkId={id}&searchHash={hash}&csrf_pb={token}&addToCart=0
   Cookies: csrf_pb={token}
   → Returns JSON with premium flag + exact pricing in cents
```

**Critical insight:** `csrf_pb` must be sent as BOTH a cookie AND a POST parameter.
